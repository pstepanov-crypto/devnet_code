В проекте собраны вспомогательные скрипты и шаблоны для автоматизации работы с сетевым оборудованием (преимущественно Cisco) и системой учёта **NetBox**.

**Основные директории:**

- **`add_devices_netbox_api/`** — добавление устройств и SFP-модулей в NetBox через API, сканирование подсетей с помощью Netmiko.  
- **`add_ssh_access/`** — массовое открытие доступа по SSH (добавление ACL) на устройствах.  
- **`add_user/`** — создание и удаление локальных пользователей на коммутаторах/маршрутизаторах.  
- **`add_vlan_leaf/`** — применение конфигурации VLAN/VXLAN на leaf-устройствах по Jinja2-шаблону.  
- **`ansible_templates/`** — пример Ansible-playbook для Nexus (создание VLAN, NVE, EVPN и т. д.).  
- **`backup_devices/`** — резервное копирование конфигураций с поддержкой нескольких типов устройств, сохранение дельты между версиями.  
- **`csv_to_yml_format/`** — преобразование CSV в YAML для последующей загрузки в NetBox (устаревший подход).  
- **`device_parse/`** — сбор PID/SN оборудования в CSV.  
- **`mac_ip_port_parsing/`** — три шага: считывание MAC-таблицы, получение IP по MAC, nslookup имени хоста.  
- **`netbox/`** — набор утилит для NetBox: добавление префиксов/устройств, создание кабелей, экспорт данных, отчёт по стойкам, боты.  
- **`parseRegular/`** — примеры парсинга вывода команд (regex) и поиск MAC-адресов по подсети.  
- **`sendCMD/`** — отправка конфигурационных команд на список устройств, включая шаблоны для Leaf/Borderrleaf.  
- **`sfp_parse/`** — сбор информации о SFP-модулях в CSV.  
- **`snmp_scanner/`** — SNMP-сканер подсети для определения модели, серийного номера и имени устройства.  
- **`update_cisco_ios/`** — автоматизация загрузки образа прошивки по TFTP и ожидание завершения.  

В корне присутствует минимальный **README.md** и различные **YAML-файлы** с параметрами подключения (`device_params*.yaml`).
