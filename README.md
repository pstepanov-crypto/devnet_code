Что важно знать новичку
Библиотеки
Большинство скриптов используют Netmiko для SSH‑доступа, requests/pynetbox для NetBox API, pandas/openpyxl для обработки таблиц, а также jinja2 для шаблонов конфигурации. Убедитесь, что эти зависимости установлены.

Файлы с параметрами
В каждом модуле есть YAML‑конфиги (device_params_ios.yaml, device_params_nxos.yaml и т. д.) — они задают логин/пароль, тип оборудования и прочие данные. Перед запуском скриптов их нужно заполнить и убедиться, что указаны правильные подсети в network_ranges.

NetBox
Скрипты взаимодействия с NetBox требуют заполнить netbox_url и netbox_token. Некоторые из них используют self‑signed сертификаты — обратите внимание на параметр verify.

Параллелизм
Для ускорения сканирования часто применяются ThreadPoolExecutor или multiprocessing.Pool. При отладке не забывайте ограничивать число потоков/процессов и тщательно логировать ошибки.

Регулярные выражения и шаблоны
Многие функции извлекают данные из CLI‑вывода по regex. При изменении версий ПО или добавлении нового оборудования проверяйте корректность шаблонов.

Файлы CSV/XLSX
Для обмена данными с внешними системами активно применяются CSV/Excel. Перед запуском скрипта убеждайтесь, что файл существует, и его структура соответствует ожидаемой.
